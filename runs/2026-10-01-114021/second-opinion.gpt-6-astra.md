## Missed / misread (per Astra)

- [medium] **Predictable VM work directory permits host-side code substitution** — examples/qemu-vm/run-vm.sh:6
  The script accepts an existing /tmp/nix-bitcoin-qemu-vm with mkdir -p and later executes through its vm link; deploy-krops.sh also executes its krops-deploy link. A local attacker who pre-creates and owns this directory can replace those entries and execute code as the host user. Allocate a private directory with mktemp -d.
- [low] **Firewall assertions leave peer restrictions silently disabled** — modules/presets/wireguard.nix:111
  With lndconnect disabled, firewall.enable=false passes despite restrictPeer=true, so its REJECT rules never run. The pinned NixOS also supports a firewalld backend that ignores extraCommands while networking.nftables.enable remains false, passing both guards even with lndconnect enabled. Assert firewall availability for both features and explicitly require backend=iptables.
