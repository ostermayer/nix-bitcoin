## What I verified clean

- `pkgs/netns-exec/src/main.c`: netns allowlist, absolute-path execv, capability drop before exec, no setuid (file cap `cap_sys_admin=ep`, owner-only 0500). Prior M-6 fix is complete.
- Secrets: nothing in the Nix store; passwords via files not argv; `umask u=rw,go=`; unlisted files locked to root; all interpolations `escapeShellArg`'d.
- onion-addresses root service: symlink refusal, single-read content validation (`^[a-z2-7]{56}\.onion$`), root-first dir construction, `chown -h`, atomic `install -T`.
- lnd macaroon ExecStartPost: root staging dir, `mv -fT`, admin macaroon read as the lnd user, 64 KiB response cap, `jq -e` fail-closed.
- Supply chain: all fetches hash-pinned, HTTPS-only, no curl|bash in build paths; btcpayserver override is version-guarded; krops pinned to a commit, not a tag.
- Wireguard preset: firewall-enable and iptables-backend assertions refuse silent rule loss; REST accept is interface- and peer-scoped; the 0.0.0.0 REST bind is a documented, deferred decision (`docs/wireguard-rest-bind.md`).
- All prior findings in `docs/security-audit-2026-08-14.md` (and the later rounds referenced in commit messages) are closed in the code as claimed.
