Audit complete. Summary of what I did and found.

## Surface map

Trimmed fork at `121406c`: ~3.3k lines of NixOS modules covering bitcoind, lnd (+lndinit, lndconnect), electrs, btcpayserver/nbxplorer, secrets machinery, onion-addresses/services, netns-isolation, wireguard preset, operator access, plus pkgs (netns-exec, lndinit, nbxplorer, krops pins) and helper scripts. Root-running code paths are few: `setup-secrets`, `onion-addresses`, the lnd macaroon `ExecStartPost` ("+"-prefixed), the wireguard peer unit, and the netns bridge/setup units. All service `preStart`/`postStart` scripts run as the service user, which collapses most symlink/race concerns to those four root paths.

## Investigation results

**Re-verified the 2026-08-14 audit closures.** All hold: clboss/CLN/joinmarket/RTL/loop/knots/bitcoind_29 are gone from the tree; M-2 (lndconnect no longer rebinds `restAddress`), M-3 (whitelist trimmed, `getpeerinfo` retention justified by lnd's health check), M-6 (netns-exec: absolute path, checked cap returns, whitelist matches the live service set exactly), L-6 (rpcauth password via file, not argv), L-8 (wireguard `wg set`, no self-re-exec), krops commit-pinned. Spot-checked each against current code.

**Verified HEAD's four fixes.** The onion regex `^[a-z2-7]{56}[.]onion$` fails closed (bash `=~` anchors the whole string, so multi-line injection can't match), and reading the file once into a variable before validating closes the check-then-read TOCTOU as claimed. `install -m 600` for electrs.toml and explicit `0640` on the cookie are correct. All `chown` calls in onion-addresses use `-h`; the populate-then-chown ordering is sound.

**Version inventory re-run** (`helper/update-flake.nix versions`): bitcoind 31.1, lnd 0.21.2-beta, btcpayserver 2.4.2, electrs 0.11.0, nbxplorer 2.6.10, lndconnect 0.2.1 — all at or above the fixed versions from the prior audit; no known advisories apply. nixpkgs pins are fresh (stable 2026-08-19, unstable 2026-08-22). The `nixpkgs-25_05` input is stale (2026-01) but provably unused in pin selection, so no impact.

## New findings
