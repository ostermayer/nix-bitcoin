## Surface map

Fork: `ostermayer/nix-bitcoin`, diverged from fort-nix/nix-bitcoin at `37931e5` (upstream merge #848). 70 fork commits to HEAD `0b35be2`. Diff vs upstream: 139 files, +2534/-7229, dominated by a deliberate service trim (clightning, joinmarket, rtl, mempool, liquid, fulcrum, loop, pool, charge-lnd, hardware-wallets removed). Retained surface: bitcoind, lnd (+lndinit, lndconnect), electrs, btcpayserver/nbxplorer, wireguard preset, netns-isolation + netns-exec, secrets system, onion services/addresses, krops/nixops deployment, CI supply chain.

## Investigation of highest-value targets

- **Backdoor sweep**: every source fetch is HTTPS + hash-pinned (btcpayserver 2.4.4 from official GitHub with regenerated nuget lockfile; nbxplorer 2.6.10; lndinit 0.1.36; krops pinned to a commit hash). Nuget lockfiles are hash-only standard format. No `curl|sh` outside docs (official Nix installer), no exfil patterns, no non-standard hosts, no remote patches, no suspicious postInstall hooks.
- **Secrets system**: rpcauth password passed via file not argv (L-6 fixed), all interpolations `escapeShellArg`d, unprocessed-file lockdown includes dotfiles, and setup-secrets is now a sandboxed root service (ProtectSystem=strict, ReadWritePaths=secretsDir only, AF_UNIX only, bounded caps).
- **Root-privilege scripts (privesc surface)**: onion-addresses refuses symlinks, validates exact v3-onion content (load-bearing, since bytes are spliced into bitcoin.conf/lnd.conf), stages root-owned dirs before handover, `chown -h` only. lnd macaroon delivery: root-only tmpfs staging, admin.macaroon read as the lnd user (symlink fail-closed), 64 KiB response cap, jq validation, `mv -fT` (symlink-to-dir safe). wireguard peer setup no longer sed-patches its own source as root. All fixes verified present in the tree, with adversarial VM tests pinning them (macaroon canary test in test/tests.py).
- **Network exposure**: lndconnect no longer rebinds REST to 0.0.0.0 (M-2 fixed); public RPC whitelist stripped of DoS/wallet methods (M-3); wireguard preset now refuses to evaluate with firewall disabled or nftables backend, accept rule is `-i wg-nb` + single peer /32, restrictPeer REJECT at chain top. Remaining known item: lnd REST 0.0.0.0 bind under the wireguard preset (deferred, documented with a breakage checklist).
- **Supply chain**: CI actions SHA-pinned + dependabot; cve-scan is fail-closed (validates report shape, counting, nonzero exit on scan errors); fetch-release refuses upstream releases by default; update-nix-bitcoin pins fork commit + prefetched hash and no longer auto-exec nix-shell; SECURITY.md honestly discloses unsigned CI tags; all fork commits carry SSH signatures.
